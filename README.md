# properties-admin

公開物件頁 repo `properties` 的**私人管理台帳**。

- 本 repo 為 **private**，且**不啟用 GitHub Pages** —— 網路上沒有任何可存取的網址。
- `index.html` 用瀏覽器直接開本機檔即可（不需 server）。
- `snippets/` 存放各物件頁共用的標準區塊原始碼。
- 對應的公開 repo：https://github.com/mac2good909777-commits/properties
